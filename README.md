# 旧网(OldNet)

> 一个"假互联网调查叙事"恐怖游戏——玩家在 2004 年风格的虚拟互联网中寻找真相。
> 当前是可玩原型;未来方向是提取成通用引擎(DeadWeb Engine,见 1.md)。
> **本项目从第一天起就按"AI 可辅助创作"设计**(见 §9)。

---

## 1. 这是什么

玩家进入一个复古假浏览器,浏览门户、论坛、搜索一个早已关闭的「旧网」,在帖子、公告与搜索结果之间拼出「黑石头/油神」事件的真相。游戏性来自检索与状态:搜索三次会看到本不该存在的东西,访问它会改变你读过的旧帖。

**演示流程**:门户 → 论坛帖子(供奉黑石、膏/油神记载、洋人祭祀日记)、学校公告栏(维修/封井/排查的官方口径)→ 搜索「黑石头/油神/克苏鲁」等关联词三次 → 幽灵结果注入 → 进入幽灵页 → 旧帖揭示被删回复与照片。

## 4. 核心架构:四条缝

| 缝 | 约定 | 目的 |
|---|---|---|
| 1 页面即数据 | 页面是 `{id,url,title,posts...}` 对象,渲染只有一个函数 | 内容与代码分离 |
| 2 状态可序列化 | 单一 state 对象,存档 = `JSON.stringify` | 确定性、回放 |
| 3 搜索单入口 | 全部检索行为走 `search(query, state)` | 注入/隐藏可集中控制 |
| 4 界面分层 | 浏览器 chrome 与页面渲染分离 | UI 与内容互不污染 |

规则形态见 2.md:数据描述符 IR + 纯函数求值器(已落地)。

## 8. AI 辅助开发的定位

项目预计以 AI 为**内容与规则的主要生产者**,人负责内核、校验与终审。这一预期反过来塑造了架构——数据化内容、规则 IR、确定性内核就是为 AI 协作铺设的轨道。

### 8.1 分工

| 层 | 谁写 | 原因 |
|---|---|---|
| 页面内容(帖子/文案/图片引用) | AI + 人审 | 纯数据,可批量化生成 |
| 规则描述符(2.md IR) | AI + 校验门 | 结构化数据,类型可校验 |
| 运行时内核(state/search/resolve/求值器) | 人 | 确定性核心,AI 不碰 |
| 浏览器 UI 组件 | 人为主,AI 辅助 | 手感和真实感靠人工调校 |

### 8.2 AI 产物的形态约束

- AI 只产出**数据**(页面描述、规则描述符、文案),不产出运行时代码路径
- 内容引用以 ID/URL 关联(如 `injectResult.pageId`),AI 不复制内容副本
- 规则条件只允许 2.md 词表内的结构化谓词——AI 输出天然被词表约束,不存在"AI 发明新语义"

### 8.3 校验门(人工闸门)

AI 产物进入仓库前必须通过:

1. **类型/Schema 校验**:页面描述与规则描述符过 TS 类型或 Zod Schema
2. **引用完整性**:pageId/URL/flag 引用必须能解析
3. **确定性检查**:规则不含时钟/随机/IO(词表天然保证)
4. **构建 + 回放测试**:`npm run build` + `npm test`(replay fixture 已就位:`tests/replay.test.ts`)

### 8.4 存档兼容纪律

- 旧内容**只追加不修改**;修改既有页面 = 破坏旧存档 → 需要迁移声明
- AI 生成新内容一律走新 ID,保证玩家老存档打开新版本时状态不失效

### 8.5 预期的协作工作流

```
剧本/线索设计 → AI 批量起草内容与规则(script/ 数据)→ 校验门(§8.3) → 人审与手感调校 → 入 script/
```

防剧透、隐藏条件(如"搜三次才出现")由规则 IR 声明,AI 与人都写同一种描述符,评审界面统一。

## 9. 创作者工作流(数据与框架完全分离)

创作者**只写 `script/` 下的文件**,框架代码(`src/`)无需改动:

1. **新叙事线**:`script/pages/` 下加一个 `.ts` 文件,`export const pages: PageData[] = [...]`——框架经 `import.meta.glob` 自动发现,论坛列表、搜索索引、404 逻辑全部自动生效
2. **规则**:在 `script/rules.ts` 末尾追加规则(只加新 ID,不改旧规则);页面揭示用 `hiddenFlag` / `revealFlag` / `deletedRevealFlag` 字段声明
3. **图片**:放 `script/images/`,引用方式 `new URL('../images/xxx.svg', import.meta.url).href`——路径写错直接构建失败
4. **类型**:`import type { PageData, Rule } from '@fw/data/types'`(别名 `@fw` 指向框架,只 import 不修改)
5. **验证**:`npm run build`(类型 + 引用校验)+ `npm test`(回放回归)

框架侧保证:加载期检查页面 ID/URL 冲突(控制台告警);未登记的 kind 渲染走 404;所有游戏行为(计数/解锁/注入/揭示)由规则数据驱动,不写运行时代码。
